# 도자기 물레 깎기 게임 (Pottery Wheel Game)

## Problem Statement
How might we let a casual web visitor feel the satisfaction of shaping pottery on a wheel, in under a minute, well enough that they want to beat their friends' score?

## Recommended Direction
2D 측면 실루엣 방식으로 반죽을 표현한다 — 물레 성형은 원래 회전 대칭이므로, 높이별 반지름 배열만 관리해도 물리적으로 정확하고 Canvas 2D만으로 구현 가능하다 (3D 라이브러리 불필요).

난이도가 오름차순인 3라운드로 진행하고, 각 라운드마다 목표 실루엣과 제한시간(동일하게 15초)이 주어진다. 3라운드 종료 후 3라운드 점수를 합산한 값으로 top-5 랭킹에 등록한다.

랭킹은 로컬 JSON 파일 스토어에 top-5로 저장한다 (배포 전 매니지드 KV로 교체 필요 — 서버리스 환경에서는 파일시스템이 휘발성이므로 프로덕션 배포 시점엔 반드시 바꿔야 함). 닉네임은 시스템이 결과 실루엣 형태를 보고 코믹하게 자동 생성한다 (예: "찌그러진 항아리").

## Key Assumptions to Validate
- [ ] 회전 실루엣 + 포인터 깎기 조작이 실제로 재미있게 느껴진다: 라운드 1개만 먼저 플레이해본다
- [ ] 3단계 난이도 진행이 플레이어에게 체감된다 (그냥 다 비슷하게 느껴지지 않는다): 3라운드를 순서대로 플레이해 난이도 차이를 확인한다
- [ ] 반지름 프로파일 차이 기반 점수 계산이 플레이어에게 납득 가능하게 느껴진다: 같은 결과물에 여러 점수 공식을 붙여 비교한다
- [ ] 로컬 파일 스토어가 개발 단계에서는 충분하다: 배포 시 매니지드 KV 교체가 필요하다는 점을 팀이 인지하고 있다

## MVP Scope
- 메인 화면 → 시작하기 버튼
- 3라운드(난이도 오름차순), 라운드별 목표 실루엣 + 회전하는 반죽 실루엣 + 포인터로 깎기 + 15초 제한시간(라운드 공통)
- 라운드 종료마다 목표와의 일치도 점수 계산, 3라운드 점수 합산 후 최종 점수 표시
- 완성 후 시스템이 자동 생성한 닉네임 부여
- 로컬 스토어에 top-5 랭킹(닉네임+점수) 저장 및 표시

## Not Doing (and Why)
- 3D 렌더링: 물레 성형은 회전 대칭이라 2D 실루엣으로도 정확함, 3D는 복잡도만 추가
- 매니지드 KV/외부 백엔드 연동: 로컬 저장으로 우선 검증, 배포 임박 시점에 교체 (지금 스코프 아님)
- 목표 모양 커스터마이즈: 난이도별 프리셋 3개로 충분, 사용자가 직접 모양을 고르는 기능은 이후로 미룸
