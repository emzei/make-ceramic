# 도자기 물레 깎기 게임 spec

## 개요
사용자가 회전하는 반죽을 포인터로 깎아 제한시간 안에 목표 도자기 모양을 만들고, 완성도에 따라 점수를 받아 전체 플레이어가 공유하는 top-5 랭킹에 도전하는 3라운드 웹 게임.

## 범위

### 포함
- 메인 화면의 "시작하기" 버튼과 현재 top-5 랭킹 미리보기
- 난이도 오름차순 3라운드, 라운드마다 해당 난이도 티어 내에서 무작위로 선택되는 목표 실루엣
- 회전하는 원기둥 반죽의 2D 측면 실루엣 표시, 목표 실루엣이 항상 겹쳐서 오버레이됨
- 마우스 포인터 및 터치 접촉으로 반죽 깎기
- 라운드당 15초 제한시간, 시간 종료 시 자동 채점
- 라운드 종료 후 자동으로 다음 라운드 진행
- 3라운드 점수 합산, 결과 모양 기반 자동 생성 닉네임
- 전체 공유 top-5 랭킹 등록 및 표시
- "다시 하기"로 즉시 재도전

### 제외
- 3D 렌더링: 물레 성형은 회전 대칭이라 2D 실루엣으로도 형태가 정확함 (idea.md)
- 매니지드 KV/외부 DB 연동: 로컬 파일 저장으로 우선 검증, 배포 임박 시점에 교체 (idea.md)
- 목표 모양 커스터마이즈: 난이도별 프리셋으로 충분 (idea.md)
- 라운드별로 다른 목표 표시 방식(상시 오버레이 vs 잠깐 표시 등) 설정: 이번엔 전 라운드에 동일하게 "겹쳐서 상시 표시" 방식만 적용. 라운드별 차등 표시는 사용자가 이후 확장하고 싶다고 밝힌 항목이라 이번 스코프에서 의도적으로 제외
- 로그인/계정 시스템: 닉네임 자동 생성으로 대체하여 불필요
- 되돌리기(undo): 원 요청에 없던 기능이며, 과도하게 깎인 상태도 그대로 채점하는 규칙(S4-3)으로 대체

## 시나리오

### S1. 메인 화면에서 게임 시작
- **Given**: 사용자가 게임 화면에 처음 접속함
- **When**: 메인 화면이 로드됨
- **Then**
  - [x] S1-1 "시작하기" 버튼과 현재 top-5 랭킹(닉네임+점수 목록)이 화면에 표시된다 (제안 기본값: 랭킹이 비어 있으면 빈 상태 문구 표시)
  - [x] S1-2 "시작하기" 버튼 클릭 → 1라운드(가장 쉬운 난이도) 화면으로 전환된다

### S2. 라운드 시작 시 목표와 반죽 표시
- **Given**: 1·2·3라운드 중 하나가 시작됨
- **When**: 라운드 화면이 로드됨
- **Then**
  - [x] S2-1 회전하는 원기둥 반죽 실루엣과, 그 위에 시각적으로 구분되는 해당 난이도의 목표 실루엣이 겹쳐서 함께 표시된다
  - [x] S2-2 15초 카운트다운 타이머가 표시되고 즉시 감소를 시작한다

### S3. 포인터로 반죽 깎기
- **Given**: 라운드 진행 중이며 반죽이 회전하고 있음
- **When**: 사용자가 포인터(마우스 또는 터치)를 반죽 실루엣 위 특정 높이에 위치시킴
- **Then**
  - [x] S3-1 포인터가 닿은 높이의 반죽 반지름이 즉시 줄어들어 실루엣 모양이 변경된다

### S4. 라운드 시간 종료 및 자동 채점
- **Given**: 라운드 타이머가 0에 도달함
- **When**: 타이머가 종료됨
- **Then**
  - [x] S4-1 그 시점 이후로는 포인터 조작이 반죽 모양에 더 이상 반영되지 않는다
  - [x] S4-2 그 시점의 반죽 실루엣과 목표 실루엣의 형태 차이를 기반으로 0~100 사이 정수 점수가 화면에 표시된다 (100 = 완전 일치)
  - [x] S4-3 반죽이 목표보다 과도하게 깎여 매우 작아지거나 사라진 경우에도, 그 상태 그대로 채점되어 점수가 표시된다 (별도의 실패 처리 없음)

### S5. 라운드 자동 전환
- **Given**: 라운드 점수(S4-2)가 표시되었고, 아직 3라운드를 모두 마치지 않음
- **When**: 점수 표시 후 일정 시간(제안 기본값: 2초)이 지남
- **Then**
  - [x] S5-1 사용자 조작 없이 자동으로 다음 라운드(다음 난이도) 화면으로 전환된다
  - [x] S5-2 다음 라운드의 목표 실루엣은 해당 난이도 티어 내 후보들 중 매번 무작위로 선택된다

### S6. 3라운드 종료 후 최종 결과
- **Given**: 3라운드 모두 완료되어 각 라운드 점수(S4-2)가 산출됨
- **When**: 3번째 라운드의 점수가 표시된 직후
- **Then**
  - [x] S6-1 3라운드 점수를 합산한 최종 점수가 화면에 표시된다
  - [x] S6-2 완성된 실루엣 형태를 바탕으로 시스템이 자동 생성한 닉네임(제안 기본값: 형용사+명사 조합, 예 "찌그러진 항아리")이 함께 표시된다

### S7. 전체 공유 랭킹 등록 및 표시
- **Given**: 최종 점수(S6-1)와 자동 생성 닉네임(S6-2)이 산출됨
- **When**: 결과 화면이 표시됨
- **Then**
  - [x] S7-1 최종 점수가 기존 top-5 안에 들면, 해당 닉네임과 점수가 즉시 전체 공유 랭킹 리스트에 반영되어 이후 모든 플레이어에게 동일하게 보인다
  - [x] S7-2 최종 점수가 top-5에 들지 못하면, 자신의 점수는 화면에 표시되지만 공유 랭킹 리스트에는 반영되지 않는다 (제안 기본값)
  - [x] S7-3 동일한 점수가 이미 랭킹에 있는 경우, 먼저 등록된 기록이 더 상위 순위를 유지한다 (제안 기본값)

### S8. 재도전
- **Given**: 결과 화면(최종 점수 + 랭킹)이 표시됨
- **When**: 사용자가 "다시 하기" 버튼을 클릭함
- **Then**
  - [x] S8-1 1라운드부터 새 게임이 즉시 시작된다

## 불변 규칙

- [x] INV-1 모든 라운드에서 마우스 포인터와 터치 접촉 모두 동일하게 반죽을 깎을 수 있다 (입력 장치에 따른 차별 없음)
- [x] INV-2 전체 공유 랭킹은 특정 플레이어나 기기에 종속되지 않고, 모든 플레이어가 동일한 top-5 리스트를 본다
- [x] INV-3 라운드 진행 중에는 목표 실루엣이 항상 반죽 위에 겹쳐서 표시된다 (현재 범위: 전 라운드 동일 방식)
- [x] INV-4 물레 위 기본 반죽(깎기 전) 크기는 모든 라운드에서 동일하다 (난이도별로 달라지지 않음). 반죽은 깎아서 반지름을 줄일 수만 있으므로(S3-1), 이 고정 크기는 모든 난이도 티어의 목표 실루엣 중 가장 큰 반지름보다 항상 크거나 같아야 한다

## End-to-end 검증

1. 앱 진입 → 메인 화면에서 top-5 랭킹 미리보기 확인 후 "시작하기" 클릭 (S1)
2. 1라운드: 목표 실루엣+반죽+15초 타이머 표시 확인, 마우스로 반죽 깎기 → 반지름 변화 확인 (S2, S3)
3. 터치 입력으로도 동일하게 깎이는지 확인 (INV-1)
4. 15초 대기 → 라운드 점수 표시 확인, 자동으로 2라운드로 전환되는지 확인 (S4, S5)
5. 2라운드에서 반죽을 과도하게 깎아 거의 사라지게 만든 뒤에도 정상적으로 채점되는지 확인 (S4-3), 3라운드까지 반복
6. 3라운드 종료 후 합산 점수와 자동 생성 닉네임 확인 (S6)
7. top-5 안에 드는 점수 한 번, 들지 못하는 점수 한 번을 각각 만들어 랭킹 반영 여부 확인, 다른 브라우저/탭에서도 같은 랭킹이 보이는지 확인 (S7, INV-2)
8. "다시 하기" 클릭 → 1라운드부터 재시작되는지 확인 (S8)
